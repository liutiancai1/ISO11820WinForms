# ISO 11820 系统现场演示脚本

## 演示准备

### 前期准备（演示前 1 天）

- [ ] 安装虚拟串口软件（com0com）
- [ ] 创建虚拟串口对 COM5 ↔ COM6
- [ ] 安装 Modbus Slave 软件
- [ ] 准备演示数据库（包含 2-3 条历史试验记录）
- [ ] 准备 PPT 或演示文档
- [ ] 测试完整流程至少 2 次

### 演示环境检查（演示前 30 分钟）

- [ ] 确认电脑正常启动
- [ ] 确认虚拟串口已创建
- [ ] 确认数据库服务正常
- [ ] 启动 Modbus Slave 并连接 COM6
- [ ] 配置 Modbus Slave（Slave ID=1, Address=0, Length=300）
- [ ] 在地址 258 设置初始值 250（25°C）
- [ ] 启动 ISO11820 系统并登录
- [ ] 关闭所有无关程序

### 第二部分：核心功能演示（15 分钟）

#### 2.1 新建试验（2 分钟）

**讲解**："首先演示如何新建一个试验"

**操作步骤**：

1. 点击 **"新建试验"** 按钮
2. 在弹出对话框中填写：
   - 产品名称：`玻璃纤维保温板`
   - 规格型号：`GB-A1-001`
   - 制造商：`XX建材有限公司`
   - 试样编号：`TEST-2026-001`
   - 试样前质量：`50.5` g
   - 操作员：`张三`
3. 点击 **"确定"**

**讲解要点**：
- "系统会自动生成产品ID和试验ID"
- "数据会保存到数据库中"
- "支持多个试样的管理"

**预期结果**：
- ✅ 提示"试验创建成功"
- ✅ 系统状态为 Idle

---

#### 2.2 开始升温（3 分钟）

**讲解**："现在演示智能温度控制功能"

**操作步骤**：

1. 点击 **"开始升温"** 按钮
2. 观察界面变化

**讲解要点**：
- "系统从 Idle 状态转换到 Preparing 状态"
- "采用软启动控制，根据温度自动调节功率"
- "< 300°C 使用 30% 功率，避免温度冲高"
- "> 700°C 切换到 PID 自动控温"

**演示技巧**：

1. **打开日志查看器**，展示详细日志：
   ```
   [INF] TestMaster状态变更: "Idle" -> "Preparing"
   [DBG] Modbus写入: 地址=0x0002, 值=0x1E00
   [DBG] Modbus写入成功
   ```

2. **在 Modbus Slave 中模拟温度变化**：
   - 地址 258：250 → 1000（10 秒）
   - 地址 258：1000 → 3000（10 秒）
   - 地址 258：3000 → 5000（10 秒）
   - 地址 258：5000 → 7000（10 秒）
   - 地址 258：7000 → 7500（10 秒）

3. **观察温度曲线实时跟随**

**讲解要点**：
- "温度曲线完全跟随 Modbus 数据实时变化"
- "这演示了系统与硬件设备的通信能力"
- "实际使用时，温度由真实的 PID 控制器提供"

**预期结果**：
- ✅ 状态显示 "Preparing"
- ✅ 温度曲线实时更新
- ✅ 日志显示 Modbus 通信成功

**应对问题**：

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 温度不变化 | Modbus Slave 未连接 | 重启 Modbus Slave |
| 通信超时 | 虚拟串口未配对 | 检查虚拟串口配置 |

---

#### 2.3 温度稳定判断（3 分钟）

**讲解**："系统会自动判断温度是否稳定"

**操作步骤**：

1. **在 Modbus Slave 中设置稳定温度**：
   - 地址 258 = 7500（750°C）

2. **观察状态变化**（仿真模式下会快速转换）

**讲解要点**：
- "系统使用三重条件判断温度稳定性"
- "1. 温度范围：745-755°C，连续 600 秒"
- "2. 温度漂移：≤ 2°C/10分钟，使用线性拟合算法计算"
- "3. 温度偏差：最大值与平均值之差 ≤ 1°C"
- "只有三个条件同时满足，才会转换到 Ready 状态"

**展示日志**：
```
[DBG] [仿真] CheckStartCriteria: Temp1=750°C, Temp2=750°C, TempInRange=true, IsStable=true
[INF] [仿真] 试验开始条件满足: 温度=750°C, 稳定=true
[INF] 状态转换: Preparing -> Ready
```

**预期结果**：
- ✅ 状态从 Preparing → Ready
- ✅ "开始记录" 按钮可用

---

#### 2.4 开始记录（3 分钟）

**讲解**："温度稳定后，可以开始正式试验记录"

**操作步骤**：

**讲解要点**：

- "开始每秒采集并保存温度数据"
- "计时器开始倒计时"

**展示功能**：

1. **观察实时数据更新**：
   - 计时器：1, 2, 3, 4...
   - 温度曲线持续绘制

2. **修改 Modbus 温度模拟波动**：
   - 地址 258：7500 → 7520 → 7480 → 7500
   - 展示温度曲线的波动

**讲解要点**：
- "温度会有小幅波动，这是正常现象"
- "系统会持续监测温度漂移"
- "满足终止条件或达到 60 分钟会自动停止"

**预期结果**：
- ✅ 状态 Recording
- ✅ 计时器运行
- ✅ 温度曲线实时更新

## 应急预案

### 问题 1：程序无法启动

**原因**：数据库连接失败

**解决**：
1. 检查 SQL Server 服务是否启动
2. 检查连接字符串配置
3. 使用备用数据库

### 问题 2：Modbus 通信超时

**原因**：虚拟串口未配对或 Modbus Slave 未连接

**解决**：
1. 重启虚拟串口软件
2. 重新连接 Modbus Slave
3. 检查串口号配置

### 问题 3：温度曲线不更新

**原因**：数据采集服务异常

**解决**：
1. 重启程序
2. 检查日志查看错误信息
3. 切换到全仿真模式
