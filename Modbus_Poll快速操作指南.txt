┌───────────────────────────────────────────────────────────────────────────────┐
│ 高级功能：查看通信流量                                                         │
└───────────────────────────────────────────────────────────────────────────────┘

    菜单：Display → Communication Traffic (或按 F2)

    可以看到所有 Modbus 报文：

    ┌─────────────────────────────────────────────────────────────┐
    │ Communication Traffic                                       │
    ├─────────────────────────────────────────────────────────────┤
    │ TX: 01 06 00 00 1D 4C 88 FA  ← 写入目标温度 7500           │
    │ RX: 01 06 00 00 1D 4C 88 FA  ← 从站响应                    │
    │                                                             │
    │ TX: 01 03 01 02 00 01 25 CA  ← 读取当前温度 (地址258)      │
    │ RX: 01 03 02 00 FA 38 44     ← 返回值 250 (25.0°C)         │
    │                                                             │
    │ TX: 01 06 00 02 00 00 E8 0A  ← 写入手动输出 0              │
    │ RX: 01 06 00 02 00 00 E8 0A  ← 从站响应                    │
    └─────────────────────────────────────────────────────────────┘

    报文格式：
    [从站ID] [功能码] [地址高] [地址低] [数据高] [数据低] [CRC高] [CRC低]

┌───────────────────────────────────────────────────────────────────────────────┐
│ 常见问题速查                                                                   │
└───────────────────────────────────────────────────────────────────────────────┘

❌ 问题：程序显示 "Modbus 通信超时"
✅ 解决：Setup → Slave Definition (F8) → 勾选 "Enable Slave Simulation"

❌ 问题：寄存器值不变化
✅ 解决：检查连接参数 (COM6, 9600, RTU, Slave ID=1)

❌ 问题：无法连接 COM6
✅ 解决：确认虚拟串口已创建 (设备管理器中查看)

❌ 问题：CRC 错误
✅ 解决：确认模式为 RTU (不是 ASCII)，参数为 9600, 8, N, 1

❌ 问题：程序读取的温度始终为 0
✅ 解决：手动设置寄存器 258 的值为 250
